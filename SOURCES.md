# Sources and Licenses

This document records the primary research sources, technical references, software libraries, and project resources used in FastMem Lab.

## 1. Research Papers

### The Dragon Hatchling: The Missing Link between the Transformer and Models of the Brain

**Authors:** A. Kosowski, P. Uznański, J. Chorowski, Z. Stamirowska, M. Bartoszkiewicz  
**Year:** 2025  
**arXiv:** 2509.26507  
**Source:** https://arxiv.org/abs/2509.26507

**Used for:** BDH architecture, synaptic memory, Hebbian learning, and the conceptual relationship between rapidly changing connections and memory.

---

### Fast Weight Programming and Linear Transformers: From Machine Learning to Neurobiology

**Authors:** Kazuki Irie, Samuel J. Gershman  
**Year:** 2025  
**arXiv:** 2508.08435  
**Source:** https://arxiv.org/abs/2508.08435

**Used for:** Fast-weight programming, matrix-valued recurrent state, outer-product memory updates, associative memory, and the mathematical mechanism implemented in FastMem Lab.

---

### Learning to (Learn at Test Time): RNNs with Expressive Hidden States

**Authors:** Yu Sun et al.  
**Year:** 2024  
**arXiv:** 2407.04620  
**Source:** https://arxiv.org/abs/2407.04620

**Used for:** Test-time adaptation, expressive hidden states, and fast-weight-like state updates during inference.

---

### Linear Transformers Are Secretly Fast Weight Programmers

**Authors:** Imanol Schlag, Kazuki Irie, Jürgen Schmidhuber  
**Year:** 2021  
**arXiv:** 2102.11174  
**Source:** https://arxiv.org/abs/2102.11174

**Role:** Foundational background source for the relationship between linear attention and fast-weight programming. This paper is not counted toward the hackathon's 2022–2026 primary-paper requirement.

## 4. Data and Experimental Inputs

FastMem Lab primarily uses synthetically generated numerical vectors for controlled experiments.

No external proprietary dataset is required for the core experiments.

Synthetic vectors are used to control:

- Memory dimension
- Number of associations
- Learning rate
- Query noise
- Random seed

This allows memory capacity and interference to be evaluated reproducibly.

## 7. Source Scope

Research claims about BDH, fast-weight programming, and adaptive memory are based on the cited research papers and official technical references.

Experimental results presented by FastMem Lab are generated by the project's own implementation using synthetic numerical inputs. They should not be interpreted as published BDH results or as reproduction results for the cited research systems.
